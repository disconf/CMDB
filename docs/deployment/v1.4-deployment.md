# V1.4 部署与上线准备

## 当前支持

- 本地开发：Go 服务监听 `8080`，Vite 监听 `5173`。
- Docker Compose：统一从 `http://localhost:8088` 访问。
- Kubernetes：前后端双副本、非 root、只读根文件系统、资源限制、存活和就绪探针。

## 本地直接启动

```powershell
cd apps/gateway-bff
$env:HTTP_ADDR=':8080'
go run ./cmd/server

cd ../web-portal
npm run dev
```

## Docker Compose

```powershell
docker compose -f deploy/docker-compose.yml build
docker compose -f deploy/docker-compose.yml up -d
```

## Kubernetes

先构建并推送 `cmdb/gateway:1.4.0` 和 `cmdb/web:1.4.0`，再修改 Ingress 域名：

```powershell
kubectl apply -f deploy/k8s/cmdb.yaml
kubectl -n cmdb rollout status deployment/gateway
kubectl -n cmdb rollout status deployment/web
```

## 上线阻断项

当前业务数据和会话仍保存在进程内存中。正式生产上线前必须接入 PostgreSQL/Redis、外部身份服务与密钥管理；否则重启或多副本会导致数据及会话不一致。
