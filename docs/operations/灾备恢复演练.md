# 灾备恢复自动化演练

脚本：`scripts/production/dr-drill.sh`

## 演练步骤

1. 从 PostgreSQL 主库导出备份并生成 SHA256。
2. 创建临时恢复数据库。
3. 将备份恢复到临时数据库。
4. 校验 public schema 表数量和 `cmdb_assets` 记录数。
5. 自动删除临时数据库，不修改生产库。

## 使用方法

```bash
bash scripts/production/dr-drill.sh
```

快速结构演练：

```bash
SCHEMA_ONLY=1 bash scripts/production/dr-drill.sh
```

指定环境：

```bash
NAMESPACE=ops-qa POD=postgres-ha-2 SOURCE_DB=ops_platform bash scripts/production/dr-drill.sh
```

成功输出示例：

```text
DR_DRILL_SUCCESS backup=... tables=... assets=... schema_only=0
```

## 注意事项

- 全量恢复耗时取决于数据库大小，应在维护窗口执行。
- 临时数据库名称带随机后缀，演练结束自动清理。
- 生产库不会被覆盖或修改。
- 建议每月至少执行一次，并保留备份及 SHA256 文件。
