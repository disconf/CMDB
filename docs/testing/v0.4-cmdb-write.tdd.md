# V0.4 CMDB 写入能力 TDD 证据

## 用户旅程

- 管理员可以登记和编辑资产，必填字段缺失时得到明确反馈。
- 每次创建和编辑都会形成操作人、时间和字段差异记录。
- 管理员可以批量导入 CSV，有效行正常写入，错误行单独反馈。
- 只读角色不能调用写接口。
