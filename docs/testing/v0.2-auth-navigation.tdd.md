## 用户旅程

- 管理员可以登录平台并看到全部授权模块。
- 只读人员登录后只能看到大屏、CMDB、拓扑和监控。
- 未登录用户访问业务页面时会进入登录页。
- 无效密码和无效会话不能访问受保护的身份接口。
- 用户可以退出登录并清除本地会话。
