# V0.1 大屏 TDD 证据

## 用户旅程

- 运维管理员打开门户后，可以看到全局资产、Agent、告警和任务态势。
- 运维管理员可以查看项目到基础设施的五层关系。
- 前端可以从统一聚合接口获取数据，不直接依赖外部中间件。
- 开发人员可以直接启动前后端完成早期功能验证。

通过真实 Chromium 页面验证了指标、容量、健康度、拓扑、告警和导航区域的渲染。浏览器发现的图表模板引用命名和 favicon 问题已修复。
