## 8. P2 审批流与审计
- [ ] 打开“Agent 与自动发现”页面，勾选“发现需审批”，执行一次 node_exporter/SSH/SNMP 扫描
- [ ] 扫描结果显示“新纳管=0”，发现的资产进入“待审批/审计”弹窗
- [ ] 对待审批资产点“通过”，CMDB 中新增/合并资产，待审批列表移除该记录
- [ ] 对另一条待审批资产点“拒绝”，CMDB 不新增资产，审计日志出现拒绝记录
- [ ] 对同一资产重复执行批准，接口应返回 422，不得重复创建资产
- [ ] 新增/编辑资产、机房/机柜、Agent 安装/卸载等管理操作后，审计日志出现对应记录
- [ ] 重启网关后，待审批记录仍可查询、批准或拒绝（审批状态来自 PostgreSQL）

## 9. P2 任务结果明细
- [ ] 发现任务卡片点击“结果明细”，弹窗显示发现/入库/合并/待审批/失败汇总
- [ ] 资源明细显示每个资产的 state/result、更新时间和说明
- [ ] 任务日志按时间显示 task.started、approval.required、item.imported、approval.approved 等事件
- [ ] 网关重启后重新打开任务结果，明细与日志仍可从 PostgreSQL 查询

## 10. P2 受控批量远程执行
- [ ] “受控批量远程执行”只提供 uptime、系统信息、磁盘、内存、Agent 状态、监听端口等只读操作
- [ ] 提交后状态为“待审批”，审批前不执行 SSH 命令
- [ ] 审批后逐台执行并显示输出、耗时和失败原因
- [ ] 输入包含 `;`、管道、重定向等 shell 注入字符时被拒绝
- [ ] 提交和审批均出现在审计日志

## 11. Kubernetes 资源采集
- [ ] “Agent 与自动发现 → K8s 资源”显示采集器可用、集群名称和 Kubernetes 版本
- [ ] 点击“立即同步到 CMDB”返回总数、新增、更新、未变化和失败数量
- [ ] CMDB 中可筛选 K8s 集群、Namespace、Workload、Pod、Service、Ingress 模型
- [ ] Kubernetes Node 按 IP 与已有 Agent/SSH 主机资产合并，不产生重复资产
- [ ] Pod、Workload、Namespace、Service、Ingress 之间存在关系数据
- [ ] 采集器只使用 get/list 权限，不具备创建、修改、删除 K8s 资源权限
