## 数据边界

`internal/dashboard.Service` 是当前大屏聚合边界。现阶段返回内存数据，后续按顺序接入：

1. CMDB 资产和拓扑数据。
2. Agent 在线状态。
3. Prometheus 和告警中心。
4. 任务、工单和发布服务。

前端只依赖 `DashboardOverview` 数据契约，不直接调用各业务微服务。

## 本地认证边界

当前认证服务使用进程内账号和随机会话令牌，用于在不部署 Keycloak、Redis 和数据库的情况下验证登录、路由守卫和功能权限。重新启动后端会使现有登录会话失效，这是开发阶段的预期行为。

CMDB 当前同样使用内存资产目录验证领域模型、分页查询和页面交互。资产服务接口已经按照后续 PostgreSQL Repository 的边界设计，替换存储层时无需改变前端契约。

生产阶段替换为 Keycloak OIDC：

1. 前端改用授权码 + PKCE 登录。
2. 网关验证 Keycloak JWT。
3. 权限服务根据身份映射角色、项目组和数据范围。
4. 删除内存账号、开发密码和进程内会话。
