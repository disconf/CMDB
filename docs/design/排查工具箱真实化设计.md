# 排查工具箱真实化设计

## 目标

排查工具箱只负责安全地发起服务端只读诊断，并把结果归档；不在浏览器侧直接连接目标服务器，也不把任意 Shell 能力暴露给用户。

## 执行架构

```text
用户/前端
  → Gateway /api/v1/toolbox/executions
  → 工具白名单与参数校验
  → 目标地址安全校验
  → 服务端执行器
      → 网络/HTTP/TLS/Prometheus/Loki
      → Kubernetes 只读 API
      → Vault 凭据 + 固定 SSH 命令
      → PostgreSQL SELECT 1 类只读查询
      → CMDB 拓扑图路径搜索
  → toolbox_executions 持久化
  → 审计日志
```

## 工具边界

- 所有工具都是只读工具，不接收任意 Shell、SQL 或 Kubernetes API 路径。
- SSH 命令由网关内置固定模板生成，动态参数只允许作为 shell 转义后的搜索词或端口数字。
- 数据库工具仅支持 PostgreSQL 连通性检查，固定执行只读查询。
- Vault 凭据只在服务端解析，响应中只保留凭据 ID，不包含用户名密码。
- 默认禁止回环、链路本地、多播和未指定地址；HTTP/TLS/SSH 连接使用服务端安全拨号器。

## 数据模型

`toolbox_executions` 保存：

- 工具 ID、名称、分类
- 目标、参数、操作人
- 状态、错误、耗时
- 结构化输出行

历史记录默认返回最近 50 条，最大 200 条；汇总按自然日统计执行次数、成功率和平均耗时。

## 工具清单

| 工具 | 执行方式 | 关键配置 |
|---|---|---|
| DNS 解析 | `net.Resolver` | 无 |
| TCP 端口探测 | 服务端 TCP 握手 | 无 |
| HTTP 接口测试 | 只读 GET，响应截断 | 无 |
| SSL 证书检查 | TLS 握手并读取证书 | 无 |
| Prometheus 查询 | `/api/v1/query` | `PROMETHEUS_URL` |
| Loki 日志检索 | `/loki/api/v1/query_range` | `LOKI_URL` |
| Pod 异常诊断 | Kubernetes API + 容器日志 | ServiceAccount 只读权限 |
| 主机健康检查 | Vault 凭据 + 固定 SSH 命令 | Vault SSH 凭据 |
| 进程查询 | Vault 凭据 + shell 转义参数 | Vault SSH 凭据 |
| 监听端口查询 | Vault 凭据 + 数字端口参数 | Vault SSH 凭据 |
| 数据库连通性 | PostgreSQL 只读查询 | Vault 数据库凭据 |
| 拓扑路径检查 | CMDB 拓扑图 BFS | CMDB 关系数据 |
